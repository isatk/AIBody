## 华山红系统 V4.7 核心特性

### 系统架构
```
┌──────────────────────────────────────────────────────┐
│ 系统逻辑层（稳定，代码实现）                            │
│ • 三叉树公排构建流程 • 佣金追溯与发放引擎                 │
│ • 双路径等级升级判定 • 钱包转账/提现/离线支付              │
│ • 防漏财校验规则 • 安全加密与反扒防护                     │
│ • 股东资格及时效判定 • 团队长激活逻辑                    │
└──────────────────────┬───────────────────────────────┘
                       │ 运行时动态读取
┌──────────────────────┴───────────────────────────────┐
│ 参数配置层（可变，数据库存储）                           │
│ • 等级价目表 • 升级累计消费阈值                          │
│ • 层级奖金矩阵 • 防漏财级差/追溯层数                     │
│ • 加入分配金额表 • 钱包转账/提现/充值限额与费率            │
│ • 手续费率 • 股东/团队长门槛人数                         │
│ • 优惠直通路径参数 • 优惠路径附加费                      │
└──────────────────────────────────────────────────────┘
```

### 核心设计原则
**代码写死逻辑，配置表暴露参数。**

### 双路径升级
- **标准路径**: V5→V13 逐级升级，累计消费 ¥100,000
- **优惠直通**: 一次性消费 ¥9,009 + ¥15 附加费，直升 V13

### 分销佣金引擎
- 每次消费向上追溯最多 9 层上级
- 防漏财规则：上级级别 ≥ 下级级别 + 2

### 用户角色
| 角色 | 说明 | 关键权限 |
|------|------|----------|
| 普通用户 | 消费¥1500成为V5会员 | 升级、推荐好友、消费 |
| 团队长 | 完成3个有效直推后激活 | 查看团队树、领取层级收益 |
| 股东 | 等级≥13且直推≥30 | 参与分红池分配 |
